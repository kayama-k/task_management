# スクリーンデザイン

Trello風タスク管理アプリ(架空案件)の見た目(配色・タイポグラフィ・余白・コンポーネントごとのスタイル)をまとめた資料。どの画面に何を配置し、何ができるかという仕様は [requirements.md](requirements.md)(要件定義書)「6. 画面要件」を参照。

> **本資料の位置づけ**: 実際に操作できるプロトタイプ [mockup.html](mockup.html) のCSSを正としてまとめたもの。見た目に変更があった場合は、mockup.html側を修正したうえで本資料にも反映すること。フロントエンド本体(`frontend/`)は現時点でJavaScript・素のCSSのままで、TypeScript + Tailwind CSSへの移行(詳細は[tech-stack.md](tech-stack.md))はまだ行っていないため、Tailwindのトークン名ではなく実際のCSS値で記載している。

## 4. コンポーネント一覧

| コンポーネント | 説明 |
|---|---|
| `.app-header` | アプリタイトル+背景ピッカーを横並び表示するヘッダー。アプリ背景に半透明の黒(`rgba(0,0,0,0.15)`)を重ねて文字を読みやすくする |
| `.bg-picker` / `.bg-swatch` | プリセット8色のスウォッチ(20×20px、選択中は白枠+影)と「画像を選択」ボタン |
| `.list` | リスト(列)。背景`#ebecf0`、角丸10px、幅272px固定 |
| `.list-title` | インライン編集可能なリスト名。フォーカス時は白背景+`#0079bf`の2pxアウトライン |
| `.card` | カード本体。白背景、角丸6px、下側にうっすら影 |
| `.card-due` | 予定日時バッジ。状態(通常/soon/overdue)により背景・文字色が変わる(1.3参照) |
| `.add-card-trigger` / `.add-list-trigger` | 「＋ カードを追加」「＋ リストを追加」の起動ボタン。リスト追加ボタンは半透明白背景でリストと同じ272px幅 |
| `.primary-btn` / `.danger-btn` | 主要操作(保存など)/破壊的操作(削除)のボタン。色は1.1参照 |
| `.modal-backdrop` / `.modal` | カード編集モーダル。背景幕は`rgba(9,30,66,0.54)`、本体は白・角丸8px・最大幅480px |

## 5. レスポンシブ

| ブレークポイント | 挙動 |
|---|---|
| 画面幅 768px以下 | ボードを横並びから縦積みに変更(`flex-direction: column`)。リスト・リスト追加ボタンの幅を100%に |

対応ブラウザは [requirements.md](requirements.md)「5.4 対応ブラウザ」を参照。
